# AI Chatbot

## Description

AI Chatbot is a simple rule-based chatbot built using Python. It responds to predefined user inputs using if-else logic and runs continuously until the user exits the program.

## Features

* Handles greetings
* Responds to predefined questions
* Help menu
* Joke command
* Exit command
* Continuous chat loop

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/hackers-228/decodelabs_task1
```

### 2. Navigate to the Project Folder

```bash
cd decodelabs_task1
```

### 3. Run the Chatbot

```bash
python chatbot.py
```

or

```bash
python3 chatbot.py
```
